## 一、一句话状态

**记账层已完全闭合并逐账户验证通过**（货币守恒、借贷相等、政府现金流分解、逐建筑对账残差全为 0）；
**经济层仍不能存活**——主因是政府持股约 70% 而交易税只覆盖约 9.5% 产出，
这是一条不含自由参数的闭式缺口，**需契约层裁决，不靠调参解决**。

> **本轮补正（两条，均为新发现）**：
> ① 经济死亡**不止一个原因**。除了上面的财政缺口（复算 0.595W），还有一条独立致死的
> **供给侧缺陷**——§8.6 的 L\* 表把上游四部门标小了 2.0~3.1 倍。两条各自都足以致死：
> 实测把税率拉到 200%（财政缺口压缩一个数量级）后，死亡时点与末态级数几乎不变。
> ② 「不能存活」这一结论**不受税率、不受起点布点、不受私有化开关影响**：
> 8 档税率 × 2 种布点 + 私有化开关共 10 组对照**全部死亡**。

## 五、纪律（必须遵守）

1. **严禁不明示修改数据**。测试里改任何字段都必须走 `internal/sim/scenario_test.go` 的
   `Scenario` 注入，并打印「字段 前值 → 后值 + 理由」。
2. **中文 Go 源文件不得用 PowerShell 的 `Set-Content` / `-replace` 改写**（GBK 往返会损坏）；
   一律用编辑工具。历史上已踩过两次。
2b. **写文件只用绝对路径。** 本会话实测：`write` 工具把相对路径 **解析到工作区根目录**，
   而不是"当前所在目录"。曾因此在 `VC_Go/tools/viz/` 下写 `README.md` 时覆盖到仓库根 README。
   **入库后已有版本历史，覆盖可回滚**；但仍按此纪律执行，因为误写会污染仓库根。
   规则：任何 `write` / `edit` 的 `file_path` 一律写完整绝对路径；覆盖既有文件前先确认路径。
3. **记账口径只有一处**：所有余额在 `internal/ledger`，所有交易构造在 `internal/book`。
   诊断代码**不得重算**分摊——必须取记账处返回的"记账事实"。
   重算会导致两处口径分叉，而全局不变量仍然全绿（已发生过一次，残差 213 万）。
4. **全局不变量 ≠ 逐账户正确**：前者是全账户求和的标量，后者是逐账户的向量。
   加新的资金流时，必须同时给逐账户对账加断言。
5. 契约文档以 `VC_Go/1.0 生产与市场模拟.md` 为唯一源，改后必须重新渲染并校验：
   ```powershell
   node VC_Go/tools/md2html.js "VC_Go/1.0 生产与市场模拟.md" "VC_Go/docs/1.0 生产与市场模拟.html"
   node VC_Go/tools/html_audit.js "VC_Go/docs/1.0 生产与市场模拟.html"   # 必须「全部检查通过」
   ```
   注意数学渲染器不支持 `\overset`。
6. 审计测试默认跳过，靠 `$env:DSH_AUDIT="1"` 启用；改动记账相关代码后**必须**跑审计套件。

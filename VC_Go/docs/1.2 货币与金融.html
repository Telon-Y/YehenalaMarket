M4.1 金融商品 = 私有化收购的进阶版本

1.0 的私有化（§4.5.1a）是"政府级 → 私有级"的一次性收购订单（对价 = 建造成本 × 建造力价）。 1.2 把它进阶为可交易的金融商品：

维度1.0 私有化收购1.2 金融商品
标的一次转让若干级的所有权每级发行一份收益权商品（1 级 = 1 份）
交易方向单向：政府 → 私有单向，只能从左往右（详下）
出资方政府 ↔ 私有级之间的一次性收购储蓄银行（买金融区发行的"债券"，见 M4.3）
定价建造成本 × 建造力价 × 倍数随建造力波动的价格（不自主波动）
收益按持股分红（§4.5.1）持有者获每周期对应分红

交易规则（2026-09-20 第 2 次裁决，纠正"顺序交易"的措辞）：

"交易不是顺序交易，而是单向交易，只能从左往右，不能同级交易， 也不能从右往左。"

即链条 政府 → 劳动力 → 金融区 是资金/股权的流向，不是"必须按次序发生的一串交易"：

允许禁止
政府 → 劳动力劳动力 → 政府（从右往左）
劳动力 → 金融区金融区 → 劳动力（从右往左）
相邻两级之间的交易同级之间（政府↔政府、劳动力↔劳动力、金融区↔金融区）
跨级直连（政府 → 金融区）

歧义标注（Ⅰ）→ 已澄清（2026-09-20 第 3 次裁决）： "不能同级交易"= A 所有的东西不能被 A 自己私有化—— 具体地："劳工不能私有化劳工所有的建筑"。即所有权主体不能从自己手里买， 这与"逐级可拆分性"无关。

第 1 步｜基准工资 baseWagei=WagePerLevel(i)/LaborPerLevel(i) （1.0 已是逐建筑：城镇 6.75、农业 5.65、庄园 5.65、金融区 6.75。）

第 2 步｜可竞标资金（A_i） πinet=本期纯利−baseWagei×在岗人数,Ai=wageBidCap×max(0,πinet) wageBidCap 默认 0.5（1.2 草案原文"最高 50%"）。

⚠️ 与 §4.5.1 的关系（必须写明，否则会重复扣一次工资）： §4.5.1 的划分顺序是「先补足自身现金池 C∗i，余额再按持股分红」。 竞标资金应当取自分红之后的剩余（即"扩大再生产资金"那一份）， 而不是在分红之前再切一刀。故上式的"本期纯利"应理解为 "扣基准工资与分红后的剩余"，与草案原文"建筑扣除工资、分红后"一致。

第 3 步｜出价与择优（本期只抬一次，避免与利润互为因果的震荡） pinew=min(pimax,pi+Ai在岗人数)

  • 抬价条件（待裁决①已定：(a)）：只在该场地本期招不满（申报量未被满足）时才抬价； 招满则不加价（否则会无谓地推高成本）。
  • 回落与衰减（待裁决②已定：(b)+(c)）：两条同时实施——
    • (b) 招满即回落：本期招满且有富余申报（说明出价过高）⇒ 溢价按 wageBidDecay 下调；
    • (c) 缓慢衰减：即使一直缺员，溢价也按 wageBidDecay 向 0 衰减， 使"降价试探"成为可能（否则只有上抬、没有下探）。
    • wageBidDecay 默认 5%/年（年化口径，与 §5.2 的 HireAnnual = 5%/年 同一约定， 每 tick 生效 5%/52≈0.096%）。
  • 不设显式上限（待裁决⑤已定：(c)）：pimax=+∞， 由 §4.1 的 10% 阈值隐式约束——抬价推高成本 ⇒ 利润率跌破阈值 ⇒ 停建、亏损解雇， 竞标资金 Ai 随之归零。故不需要额外的工资上限条款。

第 4 步｜配置（按工资从高到低）

  1. 各场地按实际人均工资 wi=baseWagei+pi 降序排序；
  2. 每级建筑需要 LaborPerLevel 人；雇佣率 hi 按 §5.2 的规则演化 （利润率 > 0 尝试增雇、< 0 解雇）——竞标只决定"优先级"，不决定"要不要人"；
  3. 依次满足：需求i=Ni×hi×LaborPerLevel，直到总人口耗尽；
  4. 未获配的申报量 ⇒ 该场地雇佣率按实际到岗/申报的比例下调（与 1.0 第 23 轮的 LaborMarketRatio 同构，但那时是全局等比，这里是按工资排序）；
  5. 仍有人口剩余 ⇒ 按 §4.2 的就业顺序进自给农场，再余为失业。

迁徙成本（待裁决④已定：无迁徙成本）：工人瞬时按工资排序择业， 不设迁移摩擦、不设每期迁移上限——因为模型里工人本来就没有"地点"这个状态， 只有"场地 × 阶级"的池（§5.1）；引入摩擦需要一个额外的人口分布状态，本版不引入。 于是排序即配置：同一 tick 内按工资降序分配完毕。

失业者参与竞标（待裁决⑥已定：(a) 参与）：失业人口在 §5.1 的失业池里， 他们就是被高价吸引的那部分劳动力，故参与排序与配置；一旦被某场地录用， 当 tick 即从失业池转入该场地的池。

第 5 步｜分阶级落到人群池

  • 人群池由"场地 × 阶级"扩展为携带实际工资的池（§5.1 的 39 池结构不变， 但每池多一个 Wage 字段）。

M8.4.1 违约规则：违约则延期（已裁决）

裁决原文："违约则延期"。

规则：当期能付多少付多少，付不出的部分不核销、不加速、不没收， 而是滚入未偿余额，并按同一利率 5%/年 继续计息（复利展期）：

outstandingt+1=outstandingt×(1+i)−本期实付

其中 i=0.05/52、本期实付 = min(应付 A, 金融区当期净额)。

情形处理
净额 ≥ A正常还本息，台账按 M8.2 推进
0 < 净额 < A部分支付；差额滚入 outstanding（延期）
净额 ≤ 0本期实付 = 0；全额滚入 outstanding 并计息（延期）

三条必须写明的边界：

  1. 没有"破产/没收"机制——1.2 不引入资产清算、不没收股权、不加速到期。 债务只能靠未来的净额慢慢还（或永远还不上，见下）。
  2. 期限语义变成"最短期限"：M8 的"5 年"是无违约情形下的期限； 一旦延期，实际结清时间后移。账本上仍记录"原始期限 5 年 + 已延期次数/金额"， 以便诊断（这与 1.0 §0.4 第 2 项"债务上限只按建造力产出计价"是同一个量级问题的两端）。
  3. 与 A7 判据的关系（1.0 侧影响）：若金融区永远还不上，这条不是问题（它是资本的债务， 不是政府的）；但若将来把"储蓄银行的债权"计入某个总量，就会与 §8.4 的 A7（政府债务上限） 产生口径交叉——故必须明确：M8 的债务记在金融区头上，不计入政府债务。

1.2-1 总述与阶段目标

货币与金融是模拟经营类游戏不可绕过的一个部分。好的货币与金融系统会在可玩性的基础上达到拟真的效果。维多利亚3至今都没有做出相对拟真的货币与金融系统，希望叶赫那拉能够在巨人的肩膀上走的更远。

本阶段将引入基础货币系统、实现基础货币功能即结算功能、引入金融业、引入投资池概念、引入金融商品概念、优化投资系统。

1.2-2 货币的三种形态与银行

货币，是一种特殊的商品，根据定义，其为人类可接受的一般等价交换物。货币具有多种形态，不幸的是，维多利亚时期正是处于实体货币向可兑付以及不可兑付货币变化的过渡期。为了相对拟真的模拟这一概念，不可避免的要引入至少三种货币结算模式——贵金属货币、可兑付货币、以及信用货币。

其中为了简化开发，我们设置贵金属本身设为锚定物，其中贵金属货币由其成色决定其发行量与价值；可兑付货币由准备金率决定其发行量与货币；信用货币由货币政策本身决定其发行量，由市场流通货物价值决定其价值。

这三种货币政策由银行建筑以不同的生产模式落实。银行购买贵金属（信用货币除外），生产货币，货币本身加入银行现金池，而银行将通过借贷的形式将货币转移给其他建筑。其中金融区便是最主要的用户之一。

这种特殊的功能使得银行建筑成为特殊的建筑。尽管其生产的货币理论上是商品，但货币如果真正制作为一种商品，当前基于货币定义的商品星系就会瞬间因为循环定义而崩塌，故而货币不能作为一般商品进入商品页面。

当前版本我们将注重于贵金属货币的开发，用于完善货币系统；更加复杂的货币系统将随着2.2版本金融补完而开发完成。

1.2-3 货币系统带来的问题

由于货币系统的到来，产生了海量的新问题：利润与再生产、工资与消费、商品价格的表示、货币的转移等等。

3.1 商品价格的表示

首先要解决的肯定是商品价格问题。当前的商品价格是微分方程的直接解，如果引入货币概念，则需要借助货币与贵金属价格之间的关系为原商品价格乘以一个系数。这个关系则是与银行货币发行政策有关的：我们设置贵金属货币的成色是其理论价值的五成（即通过成色、法定等因素强行抬高贵金属货币的含金量），则货币价值为贵金属价值的一倍。此时商品价格就转变为商品相对于贵金属的比值乘以货币与贵金属的比值。

为了区分银行的职能，我们将银行分为三类：中央银行、储蓄银行、投资银行（工商银行）。每种银行的职能与收支来往是固定的，方便逻辑编写。

如假定1单位黄金的价格恒为10,000，则每单位中央银行每周期收购20单位黄金，生产200,000货币。这些货币全部转入中央银行的现金池中。

储蓄银行与工商银行的功能需要重置工资与利润后才可实现，目前不讨论。

3.2 货币的转移与结算

其次就是货币的转移问题，当前对于购买商品时的货币支付问题相对不清晰，现在明确——每一单位的商品转移都需要有投资池之间的划账，每一单位的商品都要按照市场价格支付。这一支付发生在交易关系双方的投资池之间。

3.3 劳动力与工资

劳动力由于当前没有自己的动态工资，故而以修正参数的形式参与到市场活动中来，这一关系将被新的工资体系取代。劳动力将按照工种与所在生产建筑区分收入，其收入汇入对应阶层现金池下，并根据不同收入等级加权进行统一消费品购买。

3.4 利润与再生产

既然有了货币与购买关系，那么同样的就出现了利润与再生产。生产建筑通过买入原料卖出成品，获得毛利收入。这一部分收入将划分为工资、分红、与再生产利润。其中工资部分直接汇入对应劳动力的阶层现金池；分红则为建筑所有者的额外利润百分比分配，如一个厂为资本家所有，则该周期该建筑营业利润的10%再汇入资本家现金池；再生产利润则是扣除上述两者后的留存收益，优先填满每级建筑的500,000现金池，随后全部转入投资池。

3.5 投资池

为了实现相对正常的扩大再生产，1.2版本将引入维多利亚3的投资池概念。即所有建筑共用同一个投资池，使扩大再生产的成本全部由统一的投资池支付，而投资池的建设顺序由阶层的投资池贡献力与对应的投资倾向综合形成。

3.6 金融商品

为了更加精细的模拟市场收购行为，1.2版本将翻倍商品的数量——每种生产建筑将发行自己的金融商品，这一商品对应的是生产建筑单位等级的收益权，对应商品的所有者将获得每周期的对应分红。对应的，金融区将成为金融商品的主要购买者。

3.7 金融区

金融区是相对庄园的被动金融建筑。每一级工商业等金融商品都对应着一级金融区（农业建筑则是对应庄园）。金融区实际上是投资池收购建筑等级的具象化，只是中间隔了一层生产建筑的金融商品。目前版本将会将金融商品的价格根据建造力对应为随建造力波动的价格而非自主波动的价格。且金融商品只能被顺序交易若干次：政府所有-劳动力所有-金融区所有。各等级平级无法发生交易。

由于交易是长期发生的，故而交易成本不会计入投资池选择交易的考虑范围。

1.2-6 工资系统

由于目前系统已经可以运行，而根据运行经验，劳动力在约700周期后便会耗尽（取决于初始建筑数量——启动速度，与总劳动力数量——终点距离）。在劳动力耗尽后，由于没有工资系统，使得所有建筑的劳动力数量会随着人口衰减而减少。这是不符合逻辑的。

为了模拟劳动力在劳动力短缺的情况下的自由选择权，需要加入工资系统。即在原始工资的基础上，建筑扣除工资、分红后，可将剩余部分最高50%投入到工资提升之中，最后剩余的部分为扩大再生产资金。而劳动力将会根据工资从高到低选择工作岗位。

# 1.2 验收判决书（2026-09-20 首版）

> **性质**：1.2 自述为**开发日志**（`docs/1.2 货币与金融.md` 头部明写"未完成、不具备契约效力、
> 不推翻 1.0"）。故本判决书**分两层判定**：**机制实现层**与**经济效果层**。
> **所有数字为本次重跑**（2026-09-20），同一二进制；未引用 1.2 文档自述的实测值。

## 一、判决

| 层 | 判决 |
|---|---|
| **机制实现层** | **通过**。9 个特性开关全部可跑、**默认逐位隔离**（关闭时逐位复现 1.0）、组合与全栈均有逐 tick 不变量断言。**这是本项目工程质量最好的一块。** |
| **经济效果层** | **未通过**。唯一有效的开关（金矿 + 央行造币）以**新增货币**换取名义指标，长跑中表现为**推迟崩盘**而非修复。 |
| **能否作为 1.0 验收的替代读数** | **不能**。二者分母相同但含义不同（1.2 打开了货币注入）。 |

- **5,000 tick**：判据 **4/9**；人口 **2,303,470**（年化 **−4.38%**）、
  投资池 **7.69e10**、政府债务 **9.51e9**、资本池 **−3.75e10**、A7 越界 **2000/2000**；

## 四、不可否定的部分

| 项 | 结论 |
|---|---|

| 全栈不变量 | ✅ 全开 900 tick、9 种组合 ×1200 tick 均无违规（测试断言） |
| 会计口径扩展 | ✅ 造币/金矿/借贷台账均**计入 `Infusion`**，故 A8 不报假残差（`audit_centralbank_test.go` 有专项断言） |
| 1.0 数值不被推翻 | ✅ 1.0 路径未被 1.2 修改（回归锚点逐位一致） |

## 五、结论与建议

1. **1.2 作为"机制实现"通过验收**，可作为 1.0 之上的可选扩展层；
2. **1.2 作为"经济修复"不通过**——它没有解决 1.0 的结构性问题
   （A7 债务上限基数、真实产出见顶回落），只是用货币注入推迟了结局；
3. **不得以 1.2 的 `7/9` 替代 1.0 的验收读数**：两者分母相同（A1–A9）但**含义不同**；
4. **建议**：在 1.2 文档 §0 的"验收证据"一栏补一句
   "**判据分数不可与 1.0 基线直接比较**（1.2 打开了货币注入）"，
   以免后续引用者把 7/9 当作 1.0 的改善。

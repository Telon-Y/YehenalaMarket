## 复现命令

```powershell
$env:GOROOT="D:\Code\Go"; $env:GOCACHE="D:\Code\YehenalaMarket\out\gocache"
$env:GOPATH="D:\Code\YehenalaMarket\out\gopath"; $env:GOTMPDIR="D:\Code\YehenalaMarket\out\gotmp"
Set-Location D:\Code\YehenalaMarket\gosim

go build ./... ; go vet ./...            # 均应 exit=0
go test ./... -count=1                   # 常规：全绿

$env:DSH_AUDIT="1"
go test ./internal/sim/ -v -count=1      # 审计：70 个测试全绿（全模块 119 通过 / 0 失败）
go test ./internal/sim/ -run TestPrintAgriCapacityLimit -v   # 诊断：农业上限（耕地/劳动/专业农业停摆，R43）

go run ./cmd/market-sim -ticks 10000     # 契约指定的验收长跑（20m 人口）
go run ./cmd/market-sim -ticks 1000 -gov-startup 20 -welfare 6 -subsidy   # 校准臂：流动性 + 福利金 6 档 + 开发类补贴（R39）
go run ./cmd/market-sim -ticks 1000 -unlimited-funds   # 诊断：投资池/国库恒 ∞（ACTIVE §七 R28）
go run ./cmd/market-sim -ticks 1000 -price-mult 3      # 诊断：开局价 ×3（R31）
go run ./cmd/market-sim -ticks 1000 -static-pcost      # 对照：钳制带回退到固定 P_ref（R32/R33）
go run ./cmd/diag_govcash                # 货币守恒与借贷校验诊断

# 一键重渲染全部文档为 HTML（含契约结构校验）
powershell -ExecutionPolicy Bypass -File D:\Code\YehenalaMarket\tools\render_all.ps1
```

## 包结构 → 契约条文

| 路径 | 职责 | 契约依据 |
|------|------|----------|

| `internal/produce` | 投入申报、等比配给、短缺惩罚、自给农场 | §3.3 §4.2 |
| `internal/consume` | 消费组、财富插值、权重购买、满足度、人口增长 | §6.1–§6.5 |
| `internal/build` | 扩建规则、两条投资栈、建造队列、完工归属、雇佣调整 | §4.1–§4.4 §4.5.1b §5 |
| `internal/cohort` | 人群与阶级现金池（3 阶级 × 13 场地 = 39 池；**劳动结构逐建筑**，§5 第 20 轮） | §5.1 |

| `internal/book` | **交易语义**：每类流动一个方法，借贷两侧写在同一处（储蓄为**两步**过账） | §4.5.3 / §5.3 |

> **记账分层的关键约定**：`ledger` 只管"借贷是否相等"，`book` 只管"这笔交易的业务语义"；
> 所有余额只有一份（`ledger.Auditor`）。**诊断代码不得重算分摊**，必须取 `book` 返回的记账事实。

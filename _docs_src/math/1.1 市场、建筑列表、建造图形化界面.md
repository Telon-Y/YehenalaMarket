市场、建筑列表、建造图形化界面
	1.1版本将使用raylib作为核心部件，将市场、建筑列表、与建造页面图形化。为了方便考虑，不会额外准备视觉素材，图形化靠素材库调用绘制。1.1版本要实现基本的可玩页面，允许玩家进行操作，为2.0版本接入gui做准备。

1. 将现有纯控制台+CSV的市场模拟，迁移到raylib 图形窗口中运行，保持核心模拟逻辑完全不变。
2. 使用 raylib 内置绘图功能（无额外图片资源）绘制三个主面板：
  1. 商品市场页面（价格、供需、历史曲线）
  2. 建筑列表页面（数量、雇佣率、利润率、现金池、手动扩建）
  3. 建造队列页面（进度条、预估完成时间、紧急调控）
3. 提供基本的“可玩性”操作：
  4. 控制模拟速度（暂停 / 1x / 2x / 5x）
  5. 手动扩建 / 拆除建筑
  6. 调节部分 AI 扩张参数（如利润率阈值）
4. 为2.0完整的游戏 GUI（多本地市场、库存、地块）预留扩展点，使得后续工作平滑延续，无需重构 UI 代码。


字体使用黑体，字号20。
UI包括四个一级菜单：市场、建筑、建筑队列、其他。
市场部分由一个表示商品的二级菜单与商品详情信息结合而成。其中商品详情信息包括商品名字、商品当前价格、商品相对初始价格百分比、市场生产数量、市场消费（期望消费）数量，下有两张图表：近期价格变化图表与从开始到当前周期的总价格变化绘制。
在市场页面最下面绘制价格总表，显示各商品在同一张总价格变化图中的折线（用不同颜色表示）。其中可以选择各商品以取消在图中展示（取消按钮设置在商品二级菜单上）。
建筑列表由全部生产建筑（含自给农场）详情组合而成。其信息包括建筑名字、建筑数量（扩建中数量）、建筑雇佣率、建筑现金池、建筑利润率。在一旁有建造与拆除按钮，包括数量x1、x5、x10。当建筑原材料不足时生产受限，用红色字体表示，并显示字样。
玩家扩建的建筑逻辑和扩建建造部门类似：置顶、无视现金池。
建筑队列由若干页组成，每页包含20个建造请求。用左右键可翻页（标注页数）。建造请求包括建筑类型，已建部分/总建造力，剩余时间。

设置游戏每秒帧数为60FPS，其中20帧对应一周期。设置游戏速度x1，x2，x5。则对应20帧、10帧、4帧每周期。
